## 2. 每个控制环的频率怎么算

### 2.1 电流环（最高频）
```
f_cur = f_TIM1clk / (2 × ARR) = 170 MHz / (2 × 4250) = 20 kHz
T_cur = 50 µs = 8500 个 CPU 周期
```
为什么是 `2 × ARR`：中心对齐模式下，计数器从 0 数到 ARR 再数回 0 才算一个完整 PWM 周期。

电流采样方案需结合下管有效导通窗口选择采样时间与触发点；RCR=1 不足以单独证明采样落在正确位置。现有采样接口见 [06](06-driver-modules.md)。

### 2.2 速度环
```
f_spd = 1 kHz = f_cur / 20
```
在电流环 ISR 里用一个计数器分频，每 20 次执行一次，保证与电流环严格同步（不会抖动）。

### 2.3 霍尔事件率
```
f_hall = (rpm / 60) × 极对数 × 6
3000 rpm, 2 对极 → (50) × 2 × 6 = 600 次/秒
```
即每 1.67 ms 一次。当前在主循环轮询霍尔，尚无固定采样节拍。后续可用 EXTI 或定时器捕获边沿，再做扇区内角度插值。

### 2.4 卡尔曼滤波
```
f_kf = f_spd = 1 kHz
```
理由：它的输入是"霍尔扇区测速"，而扇区事件只有 600 Hz，再高的更新率没有新信息。

|---|---|---|---|---|

## 3. 顶层卡尔曼滤波

### 3.1 要解决什么问题
用霍尔测速 = 用两个扇区边界的时间差算速度：
```
ω = 60° / Δt
```
`Δt` 的量化误差直接放大成速度噪声（±3% 起），而且**在每个扇区边界跳变**。
直接把它送进速度环 PI，会得到：转速抖动、异响、低速尤其明显。

卡尔曼滤波做两件事：
1. 把"跳变的速度测量"变成**平滑的估计**；
2. 顺带估出**角加速度**，用于扇区内的角度预测（比线性插值准）。

### 3.2 状态方程
取状态 `x = [ω, a]ᵀ`（角速度 rad/s、角加速度 rad/s²）：

```
ω(k+1) = ω(k) + a(k)·Ts
a(k+1) = a(k)                 （假设加速度在一个周期内不变）

F = [1  Ts]      H = [1  0]      Q = diag(q_ω, q_a)      R = r
    [0   1]
```

- `R`：速度测量的方差，由霍尔测速的抖动决定（实测：让电机稳速转，统计 ω 的方差）
- `Q`：过程噪声。`q_a` 小表示"加速度变化慢"，滤波更平滑；负载突变多就加大

### 3.3 迭代（5 行）
```
预测：
  x̂⁻ = F·x̂
  P⁻  = F·P·Fᵀ + Q

更新：
  K   = P⁻·Hᵀ / (H·P⁻·Hᵀ + r)
  x̂   = x̂⁻ + K·(z − H·x̂⁻)        z = 霍尔测速
  P   = (I − K·H)·P⁻
```
2×2 矩阵，全是标量运算，约 50 次浮点操作 —— 1 kHz 下毫无压力。

### 3.4 角度用它来预测
```c
/* Ts = 1 ms，单位 rad */
theta_elec += (omega * Ts + 0.5f * accel * Ts * Ts) * POLE_PAIRS;
theta_elec  = wrap_2pi(theta_elec);
```
比 `θ = θ扇区 + ω·Δt` 多了一项 `0.5·a·Ts²`，加减速时明显更准。

### 3.5 代码骨架（后续实现示意）

下面使用紧凑协方差更新，不是完整 Joseph 形式；接入前需补齐状态、常量、有效新测量判断和数值稳定性检查。`ω = 60°/Δt` 是电角速度，若滤波器使用机械角速度，须先除以极对数，后续角度预测再乘极对数。

```c
/**
 * @brief  二阶卡尔曼滤波：由霍尔测速估计转速与角加速度
 * @param  z_omega: 本拍速度测量值，rad/s（霍尔扇区算出来的）
 * @retval 无，结果写入 kf.omega / kf.accel
 */
static void kf_update(float z_omega)
{
    /* ---- 预测 ---- */
    kf.omega += kf.accel * KF_TS;
    float p00 = kf.p00 + KF_TS * (kf.p10 + kf.p01) + KF_TS * KF_TS * kf.p11 + KF_Q_W;
    float p01 = kf.p01 + KF_TS * kf.p11;
    float p10 = kf.p10 + KF_TS * kf.p11;
    float p11 = kf.p11 + KF_Q_A;
    kf.p00 = p00; kf.p01 = p01; kf.p10 = p10; kf.p11 = p11;

    /* ---- 更新 ---- */
    float s = kf.p00 + KF_R;        // 新息方差
    float k0 = kf.p00 / s;
    float k1 = kf.p10 / s;
    float innov = z_omega - kf.omega;

    kf.omega += k0 * innov;
    kf.accel += k1 * innov;

    // Joseph 形式的简化：P = (I - K·H)·P
    float n00 = (1.0f - k0) * kf.p00;
    float n01 = (1.0f - k0) * kf.p01;
    float n10 = kf.p10 - k1 * kf.p00;
    float n11 = kf.p11 - k1 * kf.p01;
    kf.p00 = n00; kf.p01 = n01; kf.p10 = n10; kf.p11 = n11;
}
```

### 3.6 调参顺序（别乱）
1. 先让电机**匀速**转（速度环已有），记录霍尔测速的波动 → 得到 `R`（方差）；
2. `Q` 从小到大试：太小 → 响应迟钝（加速时转速跟不上）；太大 → 又变回噪声；
3. 用**阶跃给定**验证：超调 < 5%、恢复时间 < 200 ms 即合格；
4. 最后才把它接进速度环（先并联观察，不切换）。

### 3.7 什么时候不需要卡尔曼
- 如果只用 20 kHz 轮询霍尔的扇区测速，且转速 > 500 rpm，噪声可能已经够用；
- 卡尔曼的价值在**低速**（100 rpm 以下）和**需要角加速度**的场合。
- 所以：v0.2 先用一阶低通，v0.3 再换卡尔曼，两者用同一组阶跃数据对比。
