# 09 操作、构建与验证

[English](../en/09-validation-and-maintenance.md) | **简体中文** | [文档目录](../README.md)

本页是当前能力、启动许可、命令与操作参数的唯一说明入口。接线见 [01](01-hardware-and-wiring.md)，模块契约见 [06](06-driver-modules.md)。

## 当前能力与边界

- 上电 STOP，CTRL_SD 低。命令 `1` 启动固定电角度 Id/Iq 电流环，先关桥校准零偏，成功后开桥。电流控制与同步采样频率为 20 kHz。
- 霍尔用于监视，转子电角度零点与方向仍待标定。本阶段用于静止或受控台架电流调试，速度环与连续旋转控制尚未接入。
- 每相达到 ±8 A、原始值饱和、缺帧、PWM 联锁或提交窗口异常时立即关桥并锁存。三相电流和超过 1 A 持续 3 帧时锁存。母线越界、样本过期或 VREF 漂移也锁存停机。故障后须复位，命令 `0` 只停机。
- TIM1 更新中断检测缺失的 ADC 帧。母线由主循环定期采样，电流 ISR 检查母线时效。保护仍需硬件过流链路配合，模拟饱和、电气极性、ISR 最坏耗时和实际控制稳定性须实板验证。

## 串口操作

串口参数与接线见 [01](01-hardware-and-wiring.md)。命令单字符有效，不需要回车。

| 命令 | 行为 |
|---|---|
| `0` | 撤销运行许可、关桥、停 PWM 和 ADC |
| `1` | 启动同步采样，零偏标定完成后运行固定角度电流环 |
| `h` | 关桥并监视霍尔变化 |
| `+` / `-` | Iq 给定增加 / 减少 0.1 A |
| `]` / `[` | Id 给定增加 / 减少 0.1 A |
| `>` / `<` | 停机时固定电角度增加 / 减少 15°，运行中保持当前角度 |
| `p` | 打印最近一秒的任务与中断占用率，打印一次 |
| `v` | 开启 50 Hz VOFA+ 波形，再发一次关闭 |
| `?` | 帮助 |

| 参数 | 当前设置 | 源码 |
|---|---|---|
| Id / Iq 默认值与各轴范围 | 0 A，±1 A | `src/app/control/app_current.c` |
| 给定斜坡 | 每拍 0.0001 A，即 2 A/s | 同上 |
| 固定电角度默认值 | 0°，按 360° 回绕 | 同上 |
| PI 初始参数 | Kp=0.5 V/A，Ki×Ts=0.005 V/A | 同上 |
| 每轴输出电压上限 | ±1.4 V | 同上 |
| 母线运行范围 / 更新 / 时效 | 8～30 V / 10 ms / 20 ms | `src/app/control/app_control.c` |
| 运行时 VREF 允许漂移 | 相对启动值 ±50 mV | 同上 |
| 关桥等待 | 200 ms | `src/app/app/app.c` |

给定和角度在正常启停之间保留，重新启动从零电流斜坡开始。PI 增益是台架初值，电机相电阻和电感尚未实测。两轴各自限幅，当前调试范围不等于电机额定能力。

故障码由 `app_fault_t` 定义，1 为 ADC/零偏异常，2 为过流，3 为 PWM/调制/计算截止时间异常，4 为缺帧，5 为母线/VREF 异常，6 为持续三相电流和异常。零偏标定遇到偶发尖峰会重建稳定窗口，最长 102.4 ms；期间保持关桥。

上电提示后默认静默。启动、故障和命令应答仍可见。发送 `p` 可查看最近一个完整统计窗口的 `[CPU]` 表；首个窗口完成前显示 unavailable。字段含义见 [性能统计](12-performance-monitoring.md)。

在 VOFA+ 中选择 **JustFloat** 和 **115200、8N1**，以文本发送小写 `v`。固件发送小端浮点数，每帧以四字节帧尾结束。[JustFloat 协议](https://www.vofa.plus/docs/learning/dataengines/justfloat/)

每 20 ms 发一帧，通道从 0 开始。

| 通道 | 字段 | 含义 |
|---|---|---|
| 0 / 1 | `Iq` / `Id` | 同一控制周期内的实测 q / d 轴电流，A |
| 2 | `Iq_ref` | 该周期实际使用的斜坡给定，A |
| 3 | `Theta_elec` | 电流环使用的固定电角度，单位 °，范围 [0, 360) |
| 4 / 5 | `Speed_ref` / `Speed_fdb` | 预留的目标 / 实际机械转速，单位 rpm，接入速度环前均发 NaN |

停机或校准期间，前三个电流通道发 NaN。波形开启时可以继续用 `+` / `-` 调电流，串口省略文字回显。`p`、`?`、`h` 会先结束波形再执行命令；故障或启动被拒时也会切回文字提示。主循环阻塞或串口忙时跳过当帧，恢复后继续发送最新值。

## 构建与下载

唯一工程 `MDK-ARM/G474-FOC.uvprojx`；`STM32-FOC.uvmpw` 是快捷入口。

1. 从 PATH 查找 `UV4.exe`；Windows 也可用 `Get-Command UV4.exe`。未找到时查询 `HKLM\SOFTWARE\Keil\Products\MDK` 或 32 位视图 `HKLM\SOFTWARE\WOW6432Node\Keil\Products\MDK` 的 Path，再定位 UV4 并核实文件存在。
2. 仅在当前终端设置 `KEIL_UV4`。工具链/设备包要求从 `.ioc`、`.uvprojx` 读取；不修改编译选项适配个人环境，不提交本机路径或安装清单。
3. Windows 在仓库根目录 Git Bash 执行：

```bash
: "${KEIL_UV4:=$(command -v UV4.exe || true)}"
: "${KEIL_UV4:?Locate UV4.exe and set KEIL_UV4 for this shell first}"
"$KEIL_UV4" -r "MDK-ARM/G474-FOC.uvprojx" -j0 -o "../build-g474.log"
python -X utf8 tests/run_native.py
bash tests/check_structure.sh
```

Keil 日志路径相对工程目录，`../` 将日志置于仓库根目录。检查新日志的 `0 Error(s)` 并解释 warning。产物为 `MDK-ARM/G474-FOC/G474-FOC.axf|.hex`，日志和产物由 Git 忽略。

下载前核对目标 MCU、实际探针与下载配置，确认功率级处于可控停机状态。用户授权后使用已有 Keil 下载配置：

```bash
"$KEIL_UV4" -f "MDK-ARM/G474-FOC.uvprojx" -j0 -o "../build-flash.log"
```

检查 `Verify OK`、程序启动与串口日志；编译成功不等于烧录成功，烧录成功不等于转动验收。抓串口的工具退出后释放端口。

## 回归与实板验证

主机回归覆盖 FOC 坐标变换、三相 RL 模型收敛、抗积分饱和、占空比边界、零偏标定、完整帧发布、故障锁存、串口启停和既有日志/性能统计。主机模型验证软件逻辑，实际采样窗口、死区、极性和负载能力须用实板确认。

首次调试先固定电机并设置电源硬件限流。保持关桥核对六路互补 PWM、触发相位和模拟建立时间。确认 Id/Iq 给定均为零后发送 `1`，检查标定完成和静止零电流，再每次只调整一个轴 0.1 A，观察实际电流是否按给定收敛。固定角度可能使转子对齐或产生保持力矩。异常抖动、电流反向增大或限流立即发送 `0` 并断开功率电源排查。

`CURRENT` 行显示电流控制段的平均、最大耗时与达到 50 µs 的超时次数，已包含在 ADC3 占用率内。完整 ADC ISR 的最坏耗时仍需用示波器测量，目标低于 15 µs，并核对 PWM 在下一次下溢生效。验证缺帧与过流故障会立即拉低 CTRL_SD，之后重复启动命令仍被拒绝。完成电流环验证后再标定霍尔零点与插值。构建通过不能替代上述实板验收。
