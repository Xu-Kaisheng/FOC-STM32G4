# 03 技术优化路线

[English](../en/03-optimization-roadmap.md) | **简体中文** | [文档目录](../README.md)

> 本文是设计路线与验收目标，不维护当前状态或逐轮实施进度。已实现能力见 [09](09-validation-and-maintenance.md)，数值配置以源码/`.ioc` 为准。

> 数值口径：除明确标注实测外，本文控制耗时、优化收益和验收指标均为设计估算或目标，不代表当前固件已实现或已测得。

> 适用对象：本工程（STM32G474RET6 + ATK-PD6010B + BL57H95，霍尔 FOC，20 kHz）。
> 原则：**先能转 → 再转稳 → 再转好 → 最后才谈快**。没有测量数据的优化一律不做。

## 1. 度量基建（没有这个，后面全是猜）

在做任何优化之前，先把三件测量工具搭好：

| 工具 | 怎么做 | 看什么 |
|---|---|---|
| **周期计数** | `DWT->CYCCNT` 在 ISR 入口/出口打点 | ISR 周期数 + **最大/最小抖动**（跑 1 万个周期取 min/max） |
| **最坏耗时** | DWT 最大周期与 GPIO 标记相互核对 | 验证抢占与 Flash 取指造成的时序变化 |
| **波形** | DAC1(PA4)/DAC2(PA5) 输出 id/iq，示波器看 | 比 UART 打印快 100 倍，且不占中断时间 |

补充：UART 只用来打状态和慢变量（转速、温度、故障码），**禁止在 ISR 里打印**。

## 2. 第一档 P1：不做就不稳（v0.2 闭环必需）

待优化（本轮暂缓）：**8 A 软件限流**。当前电流只用于低频状态打印，尚未实现软件过流判断、快速关断和故障锁存。后续在可靠的同步采样基础上补齐，并验证过流响应时间、锁存及人工恢复；占空比上限不等同于电流限制。

| # | 优化项 | 做法 | 收益 | 代价 | 验证方法 |
|---|---|---|---|---|---|
| 1.1 | **ADC 零漂校准** | 上电、H 桥关断时采 256 次求均值，作为 0 A 的偏置 | 消除 offset，低速转矩纹波明显下降 | 上电 10 ms | 静止时三相电流读数 ≈ 0.00 A |
| 1.2 | **VREFINT 校准 VDDA** | 读内部 VREFINT + 出厂校准值，反算真实 VDDA | 电流增益误差 1~3% → 0.2% | 1 次查表 | 与万用表测的母线电压对比 |
| 1.3 | **PI 抗饱和** | 积分项独立限幅 + 退饱和反算 | 防止启动/堵转时积分飞掉，退饱和反向冲击触发 10.4 A 锁存 | +10 周期 | 给定阶跃后看电流是否过冲 |
| 1.4 | **采样窗口钳位** | 占空比限制在 [5%, 92%] | 保证三电阻采样窗口 ≥ 3 µs，自举电容能充电 | 0 | 最大占空比下电流波形不畸变 |
| 1.5 | **过流锁存复位流程** | 关桥后至少等 200 ms，排除故障后才允许人工重新使能；实现状态见 [操作说明](09-validation-and-maintenance.md) | 避免锁存未复位或故障持续时反复启停 | 主循环等待 200 ms | 先断开功率级做软件故障注入，再用示波器核对 SD 低电平持续时间 |
| 1.6 | **上电时序** | GPIO 输入 → 配外设 → CTRL_SD=0 → 启 PWM → CTRL_SD=1 | 避免上电瞬间的随机导通 | 0 | 示波器看上电时 PWM 与 CTRL_SD 的先后 |
| 1.7 | **G474 三路电流 ADC 并行采集（板已到手，同步采样待实现）** | IU/IV/IW 分配到三个独立 ADC，由同一个 PWM 定时器事件硬件触发；三路结果完整后再执行一次电流环 | 缩短三相采样时间差，改善窄窗口内的采样安排 | G474 板级迁移、触发与数据完整性验证 | 同源动态信号测通道时差；检查三相同周期、无缺帧及 PWM 更新期限 |

> G474 路线按上述 7 项推进；闭环与保护效果以实测验收为准，不能仅凭完成配置认定堵转安全。

### 2.1 STM32G474 三路电流并行采集


#### 现状与目标

- 当前 ADC1/2/3 各使用规则组单通道，由软件依次触发；尚不是三 ADC 同时采样。
- G474 目标为三个独立 ADC 各承担一路相电流，以同一 PWM 硬件事件触发，采用匹配的 ADC 时钟、分辨率和采样时间。现已核图分配 PC0/ADC1_IN6、PC1/ADC2_IN7、PB1/ADC3_IN1；同步触发配置与时序仍待验证。
- 目标是减小三相采样时差；三个 ADC 的存在本身不代表已经实现同步。
- 不预设存在“三 ADC 同时多模”配置；依据 G474 参考手册与 CubeMX 核对各 ADC 的注入触发源、同步限制及勘误。共用触发事件也不等于已证明零时差，必须测量跨 ADC 的实际偏差。

#### 板级核验与后续要求

| 项目 | 要求 |
|---|---|
| 板卡与封装 | 取得完整 MCU 料号、板卡原理图和排针定义，确认三路模拟引脚能分别连接三个独立 ADC，而非仅属于同一个 ADC 的三个通道 |
| PWM 与控制信号 | 可同时引出同一高级定时器的三组互补 PWM、三路霍尔、CTRL_SD、调试串口、SWD；核对板载外设冲突 |
| 其他模拟信号 | 保留 VBUS、VTEMP 与 VREFINT 测量安排，低速采样不得挤占电流采样窗口 |
| 模拟前端 | ATK-PD6010B 已提供电流放大和偏置，优先直接接入合适的 ADC 输入；核对输入量程、VDDA/VREF、源阻抗、RC 建立时间及共地，不默认再串接片上运放 |
| 接线约束 | 按 G474 数据手册与板级原理图核对复用；CN3 第 23 脚 5V_IN 仍禁止连接，电机相线对应关系保持不变 |

#### 实施顺序

1. **记录当前顺序采样基准**：记录三通道顺序采集的触发方式、实际采样时刻、转换总耗时、偏置及噪声。若比较闭环收益，需在相同 PWM 频率、负载和算法条件下建立同步采样基准，不能把更换触发方式的收益全部归因于并行 ADC。
2. **建立 G474 板级配置**：通过 `.ioc` 与 CubeMX 生成对应平台工程，按实际时钟重新计算 PWM、硬件死区及采样触发；迁移落地时按 [文档归属](../README.md) 只更新受影响主题，不复制引脚和参数到多个入口。SDK 与生成代码保护规则继续适用。
3. **实现共同硬件触发**：优先采用注入组，每个 ADC 每次只转换对应相电流；在 PWM 有效窗口内安排每控制周期一次的共同事件。核实中心对齐计数、重复计数器和触发边沿，避免一个 PWM 周期触发两次；不能靠连续三次软件启动代替并行触发。
4. **保证三相数据完整性**：三个 ADC 分别校准偏置和换算参数；驱动仅在同一触发周期的三路结果全部就绪时发布一个样本，并且只运行一次电流环。禁止混用上一周期结果或在 ISR 中轮询等待其他 ADC；缺失、超时或溢出按故障处理，先关闭 CTRL_SD 并锁存，禁止继续用旧值驱动。
5. **校验低侧采样窗口**：结合三相占空比、死区、光耦/驱动延时及模拟前端建立时间确定共同有效窗口。并行 ADC 无法让下管未有效导通时的电流读数变得可信；无有效窗口时不得将数据用于闭环。先保留 20 kHz、1 µs 死区、5%~92% 占空比范围与 8 A 软件限流目标，重新实测窗口裕量。
6. **接入电流环并测量**：保持算法与硬件驱动分层，在 `adc_cur` 内封装多 ADC 数据汇合；先验证采样及保护，再推进电流环。G474 若运行于 170 MHz，20 kHz 下每周期预算为 **8500 CPU 周期**；ISR 仍以 <15 µs 为目标（对应 <2550 周期），且必须赶上实际 PWM 预装载更新期限。

#### 验收与记录

| 验证项 | 方法与通过要求 |
|---|---|
| 通道校准 | 关桥状态逐路测零偏；输入已知电压核对增益，记录 VDDA/VREF、采样时间和温度 |
| 实际并行性 | 功率级关闭、断开驱动板模拟输出后，将同一合规动态信号分配到三路 ADC 输入，测量并记录幅值误差与相对采样时差；不可将三路驱动板输出直接短接。验收时差阈值由允许电流误差及最大 di/dt 推导，不能只看三个中断到达时刻 |
| 同周期完整性 | 至少记录 1 万个控制周期，验证每周期只发布一次完整三相样本，无缺帧、旧值混入、ADC 溢出或重复执行电流环；软件注入缺一路结果时，应关桥锁存 |
| 窗口与截止时间 | 示波器对齐 PWM、触发标记和 ISR 标记，核对转换总延迟、最坏 ISR 耗时、抖动和 PWM 更新余量；覆盖不同扇区及占空比边界 |
| 电流一致性 | 仅在三路采样均有效、偏置增益已校准时评估 IU+IV+IW 残差，并与顺序采样基准比较；阈值按采样链路误差预算制定，不预填收益百分比 |
| 保护回归 | 验证 CTRL_SD 上电为低、硬件死区、8 A 软件保护、故障锁存与至少 200 ms 人工恢复等待；软件限流尚未实现前不得标记为通过 |

板卡型号、引脚映射和诊断配置已核验；共同触发、时序与闭环验收仍待实施，不能提前标记完成。

## 3. 第二档 P2：转得好（v0.3）

| # | 优化项 | 做法 | 收益 | 代价 | 验证方法 |
|---|---|---|---|---|---|
| 2.1 | **死区补偿** | 按电流符号给占空比加/减 `T_dead/T_pwm` | 低速转矩脉动 ↓30~50%，相电流 THD 明显改善 | +40 周期 | 50 rpm 时看相电流是否还是台阶状 |
| 2.2 | **角度超前补偿** | `θ += ω · 1.5 · Ts`（电流环 1.5 拍延迟） | 高速时 id/iq 解耦更好，效率↑ | +10 周期 | 3000 rpm 下 id 是否还贴着 0 |
| 2.3 | **霍尔插值 + 边沿校正** | 扇区内 `θ = θ0 + ω·Δt`，跳变时用霍尔重同步 | 消除 60° 角度台阶 | +20 周期 | iq 纹波 FFT，看 6 倍频分量 |
| 2.4 | **电流环零极点对消** | `Kp = L·ωc`，`Ki = R·ωc·Ts` | 电流环带宽可到 1 kHz 且不过冲 | 需实测 R/L | 电流阶跃响应（上升时间、过冲） |
| 2.5 | **速度环抗噪** | 用扇区周期测速 + 一阶低通（或 FMAC 做 IIR） | 转速波动 ↓，异响消失 | +30 周期 | 低速 100 rpm 时听声音、看转速曲线 |
| 2.6 | **启动三段式** | 对齐（d 轴 2 A，500 ms）→ 开环加速 → 切闭环 | 起动不撞过流、不反转 | 0 | 冷启动 20 次全部成功 |

> 2.1 和 2.3 是这套硬件收益最大的两项：死区 1 µs 占 2%，霍尔只有 60° 分辨率。

## 4. 第三档 P3：转得快 / 静（v0.4+）

| # | 优化项 | 做法 | 收益 | 代价 | 验证方法 |
|---|---|---|---|---|---|
| 3.1 | **CORDIC 替换 sin/cos** | 写角度 → 读 cos/sin，替代 `arm_sin_cos_f32` | ISR −100~200 周期，且**消除三角函数的抖动** | 接口复杂度 | DWT 前后对比，抖动 < 5% |
| 3.2 | **ISR 搬到 SRAM** | `__attribute__((section(".RamFunc")))` + 链接脚本 | 消除 Flash 取指不确定性 | 链接脚本改动 | DWT 的 max−min 差值 |
| 3.3 | **d/q 前馈解耦** | `vd += −ω·Lq·iq`，`vq += ω·Ld·id + ωψf` | 高速动态响应↑，id/iq 互扰↓ | +30 周期 | 高速下加负载，看 id 波动 |
| 3.4 | **Flash 取指时序评估** | 按 G474 文档检查加速与等待周期配置 | 降低最坏执行时间 | 需实测 | DWT 与 GPIO 波形对比 |
| 3.5 | **提升 PWM 频率** | 20 kHz → 30 kHz（需实测光耦） | 电流纹波↓、噪音↓ | 死区占比↑、采样窗口↓ | 示波器看 PWM 边沿是否还干净 |
| 3.6 | **无感融合（可选）** | 反电势观测器 + 霍尔互补滤波 | 高速平滑度↑ | 大 | 与纯霍尔对比 iq 纹波 |

## 5. 暂时不做（记录备选，避免走弯路）

| 项 | 为什么先不做 |
|---|---|
| 弱磁控制 | 24 V / 3000 rpm 够用，母线上限也没到 |
| MTPA | 表贴式 `Ld≈Lq`，无凸极收益 |
| HFI 高频注入 | 有霍尔，零速不需要 |
| 单电阻采样 | 板子是三电阻，不需要重构 |
| 过调制 | 提高电压利用率，但采样窗口会崩，且本机不需要 |
| 死区自适应（按电流幅值） | 先做固定补偿，收益 90% |

## 6. 反优化清单（看起来有用，实际有害）

| 做法 | 为什么错 |
|---|---|
| 在 ISR 里用 `printf` / 浮点除法 / 查大表 | 不确定延迟，直接破坏电流环时序 |
| 速度环用瞬时差分测速 | 霍尔测速噪声被放大 10 倍，必须低通或观测器 |
| 盲目把 PWM 提到 50 kHz | TLP2355 光耦 + IR2110 的延时会把死区吃掉，波形失真 |
| 只用 2 相电流省一个通道 | 三电阻同时采样能互相校验，省这一路没意义 |
| 忽略死区做 PI 调参 | 调到“不抖”的 PI 参数其实是掩盖了死区畸变 |

## 7. 迭代路线图

```
v0.1  开环六步          验证：相序、霍尔序列、转向、死区          [无优化]
迁移  G474 板级与采样   已核图 → 三 ADC 并行 → 时序/保护验收      [同步采样待实现]
v0.2  电流环闭环        P1 全部 7 项（G474 路线含并行采样）       [能稳定转]
v0.3  速度环闭环        P2 的 2.1/2.2/2.3/2.4/2.5/2.6            [转得好]
v0.4  性能与鲁棒性      P3 的 3.1~3.4 + 故障状态机 + 看门狗        [转得稳]
v1.0  收尾              文档、参数表、标定流程、回归测试           [可交付]
```

每升一版必须留下：
1. 一组合格的波形（相电流、iq 阶跃、转速阶跃）；
2. 一张实测的周期/抖动表；
3. 一段写在 `docs/` 里的“这一版改了什么、为什么”。
