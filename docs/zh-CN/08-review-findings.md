## 1. G474 ADC 样本完整性

三相电流分别由 ADC1/2/3 规则组依次读取；只有三路的启动、轮询、读取与停止均成功后才发布一次完整样本。任一路失败返回 0 且不覆盖旧输出，调用者必须将本次结果视为无效并关桥锁存。ADC4 独立承担母线监视，不与三相电流混用。

主机回归对每个电流 ADC 的各阶段注入失败，验证不会发布残缺样本；实际同步触发、电流环和快速保护尚未实现。

## 2. PWM：先 apply_step 再开桥的矛盾在哪里

顺序本身表达的意图合理：先配好换相，再给功率级使能。修复前冲突在被调用函数的检查条件：

1. `bsp_pwm_start()` 开三相，输出使能掩码为 `0x555`。
2. 首步 `apply_step()` 选择 U+V-，关闭 W 相，使能掩码变成 `0x055`。
3. `bsp_pwm_enable_bridge(1)` 再调用 `bsp_pwm_check_ready()`。
4. `bsp_pwm_check_ready()` 要求掩码必须是 `0x555`，因此拒绝开桥，CTRL_SD 仍为低。

已修复：保留三相自检；`bsp_pwm_enable_bridge_sixstep(high, low)` 精确检查指定两相成对使能及第三相悬空，并返回开桥结果。两类开桥均检查死区、周期、计数模式、预装载及输出极性；开桥前提交 CCR 预装载。应用在联锁失败时退回 STOP，不再误报正在运行。使能输出通道表示允许输出互补 PWM，不表示同一桥臂上下管同时导通。

## 3. 正点原子样例的霍尔序列

只读检查的源压缩包：
`datasheet/【正点原子】电机驱动板&电机/2，ATK-PD6010B直流无刷驱动板资料/1，实例程序/BLDC_PMSM专题实验（DMF407电机开发板）.zip`。

压缩包内 `实验9 BLDC专题实验/实验9-1 BLDC基础驱动/Drivers/BSP/TIMER/bldc_tim.c`：

- 第 168 行读取霍尔状态的注释明确为 `顺序6,2,3,1,5,4`。
- 第 175 行只判断状态值是否位于 1～6。
- 第 177 行使用 `pfunclist_m1[step_sta-1]()` 查找对应的换相函数。

同一实验的 `Drivers/BSP/BLDC/bldc.c` 第 107～117 行将 U/V/W 分别放在 bit0/bit1/bit2；本工程将 U/V/W 放在 bit2/bit1/bit0。仅做位序换算，该样例序列对应本工程的 `3→2→6→4→5→1`，循环起点移到 1 即 `1→3→2→6→4→5`。

因此，“合法数值是 1～6”和“转动时按 1→2→3→4→5→6 出现”是两件不同的事。样例用原始编码查换相表，没有把原始编码减一直接乘 60°。

后续已按维护者意见将 `bsp_hall_get_sector_deg()` 改为查表：`1→3→2→6→4→5` 对应 `0°→60°→120°→180°→240°→300°`。S1 仅作相对零点，位序换算不等于完成本机 BL57H95 的转向及电角度偏移标定。该函数当前未被开环控制调用。

## 4. 本轮落实及验证范围

- 新增 `bsp_pwm_stop_emergency()`，在致命异常及 `Error_Handler` 中先拉低 CTRL_SD，再清除 TIM1 的 MOE/AOE、六路使能和 CEN。
- 实际模式切换时，先关桥、停 PWM，再在主循环等待 200 ms；命令完成后重新读取调度时间。
- 8 A 软件限流按维护者要求暂缓，已记入 README 与优化路线；当前未实现。
- 硬件验证方法见 `06-driver-modules.md`。未烧录，未取得故障关断延迟或 GPIO 波形实测结果。

- 验证结果：当前环境可正常读取设备包；完整 Keil 重编译通过，0 Error(s)、0 Warning(s)。实际 src 模块与 HAL 替身构成的主机回归通过；Core 改动均位于 USER CODE 区。具体方法与硬件验证边界见 `09-validation-and-maintenance.md`。
