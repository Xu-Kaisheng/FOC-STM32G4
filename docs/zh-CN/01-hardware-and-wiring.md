# 01 硬件架构与接线（STM32G474 + ATK-PD6010B + BL57H95）

[English](../en/01-hardware-and-wiring.md) | **简体中文** | [文档目录](../README.md)

唯一主控是 STM32G474RET6 / DevEBox Ver.20。开发板原理图与 DS12288 Rev 6 已核对，完整排针编号和照片方向见 [11-g474-board-guide.md](11-g474-board-guide.md)。

## 1. 系统拓扑与状态

24 V 电源 → ATK-PD6010B → 电机 U/V/W；电机霍尔接驱动板 CN2，MCU 通过 CN3 连接六路 PWM、CTRL_SD、三相电流、VBUS 和霍尔信号。模拟输入未隔离，MCU 与驱动板须共地。

当前固件只做关桥诊断，GPIO 霍尔轮询、ADC1/2/3 顺序采样、ADC4 母线监视及串口性能统计已实现。开机 PWM demo 已完成测试并关闭，开桥仍禁用；电流环、同步采样及 8 A 快速限流尚未实现。

## 2. 驱动板关键电路与换算（读原理图得到，不是猜的）

| 项目 | 结论 | 依据 |
|---|---|---|
| PWM 极性 | **高电平 = 上管导通**（非反相） | PWM_UH→TLP2355 的 1 脚(A)，3 脚(C)→220R→GND；手册 2.1.1 "输出信号跟随输入信号" |
| PWM 驱动电流 | 每路约 `(3.3-1.5)/220 ≈ 8 mA`（MCU 引脚输出，LED 阳极直连 MCU） | R5/R21/… = 220R 接 GND |
| 上下管 | 6 路完全独立输入，**死区必须由 MCU 产生** | IR2110 的 HIN/LIN 分别来自 2 个光耦 |
| 相电流 | `V_AMP = 1.25V + 0.12 × I`，即 `I = (V-1.25)/0.12` | 20mΩ × 增益6，偏置 1.25V |
| 电流量程 | 0 → 3.3V 对应 −10.4A → +17.1A；硬件过流点 **10.4A**（+0.5A 迟滞） | 手册 2.1.4 |
| 相电压/BEMF | `Motor_x = 25 × V_BEMF`（分压 12K+12K+1K） | 手册 2.1.3 |
| 母线电压 | `POWER = 25 × V_VBUS`（满量程 82.5V） | 手册 2.1.11 |
| 温度 | `VTEMP = 3.3 × 4.7/(Rt+4.7)`，Rt 为 10K@25℃ NTC | 手册 2.1.11 |
| 关断 | `CTRL_SD = 1` 使能 H 桥，`=0` 关闭 | 手册 2.1.5 |
| 过流保护 | R70 已焊 = **锁存**：过流后即使电流消失 H 桥也保持关闭，**必须 CTRL_SD 拉低一次才能复位** | 手册 2.1.5 |
| 霍尔/过零 | JP3 选：1-2=霍尔（默认），2-3=过零检测 | 手册 2.1.8 |
| CN3 第 5 脚 | JP1 选：1-2=ENCZ，2-3=R_BREAK（制动控制） | 手册 2.1.7 |
| 编码器供电 | JP2 选：1-2=5V（默认），2-3=11V | 手册 2.1.9 |

> ⚠️ **ADC 基准陷阱**：驱动板模拟信号满量程是它自己的 VCC3.3（另一颗 LDO），
> MCU 的 ADC 基准是 VDDA。两者差 1~3% 是常态。
> 当前由 ADC4 采集内部 VREFINT 反算 VREF+，补偿电流与母线换算；外部放大器零偏与增益仍需单独校准。

## 3. 电机参数（BL57H95 / 57BLY95-230-001，57 法兰 95 机身）

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| 相数 | 3 | 极数 | **4（2 对极）** |
| 额定电压 | 24 VDC | 空载转速 | 4000 rpm |
| 额定转速 | 3000 rpm | 空载电流 | 0.4 A |
| 额定转矩 | 0.33 N·m | 额定电流 | 6.6 A |
| 额定功率 | 105 W | 绝缘等级 / 重量 | B / 1.0 kg |
| 线序 | 共 8 根：相线 **U / V / W**，霍尔 **VENC(+5V) / DGND / HALU / HALV / HALW** | 编码器 | **无**（8 根里没有 A/B/Z） |

由此算出：

- **2 对极**：电角频率 = 2 × 机械频率。3000 rpm = 50 rps → 电气 100 Hz、电气周期 10 ms，
  **一个霍尔扇区 1.67 ms ≈ 33 个 20 kHz 控制周期**——在同转速下比 8 极电机的扇区时间长 2 倍，霍尔插值很好做，
  低码率下也不会出现角度台阶感。
- 转矩常数 `KT = 0.33/6.6 ≈ 0.05 N·m/A`；空载 4000 rpm 反推 `Ke ≈ 24/4000 ≈ 6 V/krpm`（线反电势，以实测为准）。
- 规格书**没给相电阻和相电感**，而电流环 PI 必须要 → 实测：
  - 万用表量任意两相出线：`R_线 = 2 × R相`；
  - LCR 表量任意两相：`L_线 = 2 × L相`；
  - 典型 57 无刷：R相 0.5~1 Ω、L相 1~2 mH，L/R 约 1~2 ms。
- 启动风险：6.6A 额定、24V，堵转或"先给电压再闭环"会瞬间撞驱动板 **10.4A 硬件锁存**
  （论坛上正点原子这套电机 + MCSDK 一直报过流就是这个原因）。因此必须：
  1. 软件限流 ≤ 8 A；
  2. 电流给定加斜坡（每拍限幅）；
  3. 先做对齐（开环定位）再切闭环，不要直接给满占空比。

## 4. 接线

### 4.1 功率部分

| 驱动板端子 | 接到 | 说明 |
|---|---|---|
| CN1 `VIN` | 24V 电源 **+** | 线径 ≥1.5 mm²，尽量短 |
| CN1 `GND` | 24V 电源 **−** | 与 MCU 的 GND 必须再单独连一根（见 4.3） |
| CN1 `Motor_U/V/W` | 电机 U / V / W | 按标号一一对应接。**相序和霍尔是对应的，不能像有刷电机那样随便换两根**——要换转向在软件里做（电角度 +π，或把 V/W 的 PWM 通道对调） |
| CN4 | 制动电阻（可选） | 高速急停用，20Ω/100W 起；不用可空 |

电源建议 24V / 10A（≥240W）开关电源。首次上电可先用 12V 限流电源试。

### 4.2 电机霍尔（CN2，1×8P HT396R）

电机只有 3 根霍尔信号线 + 独立的霍尔德电源/地，接到 CN2：

| CN2 脚 | 板上信号 | 电机线 | 说明 |
|---|---|---|---|
| 1 | HALL W | **HALW** | 经 1K + 4.7K 上拉 + 102 滤波 |
| 2 | HALL V | **HALV** | 同上 |
| 3 | HALL U | **HALU** | 同上 |
| 4 | GND | **DGND** | 霍尔地，用细线单独走，别和 24V 回流的粗线共用 |
| 5 | VENC（JP2 1-2 = 5V） | **VENC** | 霍尔电源 5V |
| 6 | ENC Z | 空 | 本电机无编码器 |
| 7 | ENC B | 空 | |
| 8 | ENC A | 空 | |

> ⚠️ **顺序陷阱**：CN2 的排列是 W→V→U→GND→VENC，而电机出线是 U/V/W 一束、VENC/DGND/HALU/HALV/HALW 一束。
> 不要按“线的顺序”一一对应插，必须按上表按信号名对。

接 MCU 前应实测 CN3-2/4/6 高电平，并对照 G474 数据手册的输入条件；不能把驱动板霍尔电源 5 V 直接当作 MCU 信号电平。

### 4.3 控制接口（CN3 → STM32G474RET6）

| CN3 | 信号 | G474 引脚 | 功能 |
|---:|---|---|---|
| 2 / 4 / 6 | HALL U / V / W | PC6 / PC7 / PC8 | 上拉 GPIO，当前主循环轮询 |
| 8 | VBUS | PB12 | ADC4_IN3，×25 |
| 10 / 12 / 14 | AMP_IU / IV / IW | PC0 / PC1 / PB1 | ADC1_IN6 / ADC2_IN7 / ADC3_IN1 |
| 17 / 18 | PWM_UH / UL | PA8 / PB13 | TIM1_CH1 / CH1N |
| 19 / 20 | PWM_VH / VL | PA9 / PB14 | TIM1_CH2 / CH2N |
| 21 / 22 | PWM_WH / WL | PA10 / PB15 | TIM1_CH3 / CH3N |
| 24 | CTRL_SD | PC9 | 高有效，初始化低；当前禁止拉高 |
| 7 / 16 | GND | GND | 两根均共地 |
| 15 | VTEMP | 未配置 | 暂不接 |
| 23 | 5V_IN | **禁止连接** | 避免反灌 |
| — | 调试 TX / RX | PB10 / PB11 | USART3，115200 8N1，3.3 V 逻辑 |

所选引脚已按开发板原理图与 DS12288 Rev 6 核验。**OLED/TFT J3 必须空置**，它并联 PB12～PB15、PC6/PC7。Flash 占 PA15/PC10/PC11/PC12，LED 占 PC13/PD2，按键占 PA0/PA1，均与本方案不冲突。USB PA11/PA12、SWD PA13/PA14、晶振 PF0/PF1 与 PC14/PC15 保留。

PB10→USB-TTL RX，PB11→USB-TTL TX，GND 共地，115200 8N1。

CN3-8 是母线分压输出，接 PB12；开发板 USB 的 VBUS 是 5 V 电源网，二者不能相接。CN3-23 禁接，CN3-1/3/5 编码器与 9/11/13 反电势暂不接。

### 4.4 驱动板跳线

| 跳线 | 默认位置 | 含义 |
|---|---|---|
| JP1 | 1-2 | CN3-5 为 ENCZ，本电机不用 |
| JP2 | 1-2 | 霍尔/编码器供电 5 V |
| JP3 | 1-2 | CN3-2/4/6 为霍尔信号 |

## 5. 当前参数与验证顺序

| 项目 | 当前值 |
|---|---|
| 系统时钟 | HSI+PLL 170 MHz |
| TIM1 | 中心对齐 20 kHz，PSC=0、ARR=4250、RCR=1 |
| 死区 | CKD=1、DTG=149，对应 1 µs |
| ADC1/2/3/4 | 42.5 MHz，12 位，247.5 周期，规则组软件触发 |
| 状态监视 | 每 500 ms，轮询超时参数 1 ms |
| VBUS | `raw × VREF实测值(V) × 25 / 4095`，仅监视，已补偿参考电压，未实现过欠压保护或分压增益校准 |
| 电流/速度环目标 | 20 kHz / 1 kHz，电流环每周期 8500 CPU 周期，尚未实现 |

先核对排针、共地与 J3 空置；只连调试器、串口检查诊断日志。功率级关断时测模拟输入电压：24 V 母线分压约 0.96 V，零电流约 1.25 V。手转核对霍尔状态。2026-11-17 用户反馈开机 PWM 测试正常、死区实测 990 ns；已关闭临时 demo，保留 1 µs 硬件死区，PC9 保持低；后续复测需另行启用关桥测试；检查每对上/下管互补、20 kHz 周期与 1 µs 双低死区。现阶段不能依据编译或低频采样结果直接解锁带载。

相线和霍尔对应关系保持固定，方向调整在软件完成。软件 8 A 限流仍待实现；验证方法见 [09-validation-and-maintenance.md](09-validation-and-maintenance.md)。

COM 六步接口保持三相 CCR 为相同占空比，高相 PWM1、低相强制无效、第三相两路关闭，模式与使能一次提交。关桥验证须覆盖全部六路的正反向换相、低侧常通、悬空相、死区与载波连续性；原临时 PWM demo 的测试结果不能代替 COM 换相验证。接口约束见 [PWM 驱动](06-driver-modules.md)。
